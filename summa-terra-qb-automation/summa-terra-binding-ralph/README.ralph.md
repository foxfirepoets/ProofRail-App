## What ralph will build

The Alembic migration + a **plug-and-play IIF/CSV catalog loader** that ingests the QB Summa Terra
`Import_Files/` CSVs into the AI Accounting Hub canonical store — one command populates every catalog and
verifies it, mirroring the "upload to QuickBooks and it auto-populates" experience on the canonical side.

> This is a **scaffold that extends an existing repo.** No app code is built into THIS folder. Everything ralph
> writes lands in **TARGET_REPO** = `../ai-accounting-hub-ralph` (the completed prior build). This workspace only
> holds the plan, specs, and ralph state — so the prior build's `.ralph/` and git history stay untouched.

Chunks (5 total):
- CHUNK_1_SCHEMA: add the dimensioned models + migration `20260627_1300_summa_terra_binding` (8 tables, 6 cols, view)
- CHUNK_2_PARSE: pure CSV/IIF parsers → typed catalog rows (no DB)
- CHUNK_3_CATALOG: idempotent upsert of COA + Classes + Cost Codes (resolves account name→number)
- CHUNK_4_NAMES: idempotent upsert of Vendors + Customer:Jobs
- CHUNK_5_BOOTSTRAP: one-command `python -m app.catalog.bootstrap` with split-at-file-level + bucket assertions

## The payoff (after BUILD COMPLETE) — plug and play

```bash
cd "../ai-accounting-hub-ralph"
python -m app.catalog.bootstrap \
  --parent      "STV — Summa Terra Ventures" \
  --partnership "STV — HL Hunter's Landing" \
  --imports     "/c/Users/Administrator/Desktop/QB Summa Terra/Import_Files"
```
Loads both companies' catalogs from the CSVs, runs the split-at-file-level + bucket + no-orphan + idempotency
assertions, prints a GREEN/RED summary, exits 0 on success. Re-run any time — it is idempotent.

## Monitor Progress

```bash

```

## When ralph gets stuck

1. Read `.ralph/errors.log` for the failure pattern.
2. Add a guardrail to `.ralph/guardrails.md`.
3. Fix the specific broken file in TARGET_REPO manually if needed.
4. Point `.ralph/state.md` at the stuck task; restart the loop.

## Chunk / Build Completion

- `<promise>CHUNK COMPLETE: CHUNK_N_*</promise>` → progress logged, ralph advances.
- `<promise>BUILD COMPLETE</promise>` → run the gate once more, then run the bootstrap command above.
